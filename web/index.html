        AutomataStudio — quick guide

        1. States — add them in the left panel. Select one to set it as the start state, mark it as accepting, rename or delete it.
        2. Alphabet — add the symbols the automaton reads. One character each.
        3. Transitions — pick a source, a symbol (ε included) and a target. Parallel symbols between the same two states share one arrow.
        4. Canvas — drag states to rearrange, scroll to zoom, drag the background to pan. Double-click a state to toggle whether it accepts.
        5. Simulate — type a string and step through it. Active states and the edges just taken are highlighted in red.
        6. Convert — subset construction, DFA minimization and the trivial DFA→NFA view. Each one shows its process before you apply it.
        7. Files — Save downloads a .afjson file that the desktop app opens, and Open reads the same format.

        Keyboard: Ctrl+Z undo · Ctrl+Y redo · Enter simulates · ← → step through a simulation.
